# Superfactory Brand Assets

These files are the supplied Superfactory brand artwork, renamed for stable
application URLs:

- `superfactory-app-icon.png` — website/app icon
- `superfactory-logo-black.png` — black mark on brand yellow
- `superfactory-logo-yellow.png` — yellow mark on brand black
- `superfactory-social-tagline.png` — social preview/tagline header
- `superfactory-wordmark-dark.png` — dark horizontal wordmark
- `superfactory-wordmark-light.png` — light horizontal wordmark

The `*-cropped.png` wordmarks are centered crops of the supplied horizontal
artwork with only the solid background made transparent. They are used in
compact launcher and sign-in layouts without changing the logo or lettering.

The Tauri icon set under `desktop/src-tauri/icons/` is generated from
`superfactory-app-icon.png`.
