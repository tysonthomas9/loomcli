The 60-second decision tree

A CLI command — loom <noun> <verb>
internal/cli/<noun>/. If that directory does not exist, grep -rn 'Use:\s*"<verb>' internal/cli/. For loom data … see the exception below.
An HTTP route
Grep for the path string, never the package name — routes are not always registered by the module you would expect. Start at internal/webui/app/routes.go (outer mux) and internal/webui/handlermux/handlermux.go (nested workspace mux).
A UI screen
internal/webui/frontend/src/router.tsx is the declared single source of truth for routes; it maps to a file in src/views/.
The shape of an API request or response
api/openapi.yaml. It is the contract; the Go and TypeScript types are both generated from it, and both have staleness gates.
A core domain type
internal/domain for control-plane objects (workspace, repo, role, agent, skill, connector, daemon profile) and the Err… sentinels. internal/entity for canonical issue/comment/dependency types. internal/types for the oldest layer — status enum, IDs.
How something is persisted
internal/store holds interfaces only. The implementation is in internal/infra/fleetdb.
Why something is the way it is
docs/adr/ first, then git log -S'<symbol>' and git blame. Commit messages carry more reasoning than the docs do.
Whether a rule is actually enforced
scripts/check-*.sh and .golangci.yml. If it is not mechanised, treat it as intent rather than fact.

The layering, and the lint rules that enforce it

Dependencies flow sdk → infra → webui → cli. This is not a convention you can quietly break — five named depguard rules in .golangci.yml fail the build:

RuleSays
sdk-leafThe leaf packages (types, entity, notify, agenterr, httpclient, ops, …) may import nothing from infra, webui, or cli.
infra-isolationInfra packages (rpc, sessions, lockfile, kv, …) may not import webui or cli.
webui-isolationinternal/webui/** may not import internal/cli. Dependencies run the other way.
handler-layer-isolationAnything under **/handler/** may not import store, backend, notify, or webui/daemon. Handlers go through internal/webui/service.
data-isolationinternal/cli/data is an sdk-only surface and may not import its own parent internal/cli.
The exception you will hit first

Because of data-isolation, internal/cli/data cannot call cli.RegisterCommand like every other command family. It exports Commands() instead, and cmd/loom/main.go registers them by hand. loom data is the family you will use most — and it is the one wired differently.

The web layer

  • internal/webui/app/ — the Server struct, startup, and the route table.
  • internal/webui/handlers/<domain>/ — HTTP handlers, one directory per domain (issues, agents, terminal, git, skills, workflows, webhooks, prreview, approvals, driverapi, taskrunapi, onboarding, health, localsettings, workspace, misc, agentcontrol). One exception to the rule: handlers/connectors/ holds only connectors_e2e_test.go — the connector HTTP handlers live in handlers/driverapi/connectors.go.
  • internal/webui/service/ — the service layer handlers are required to call.
  • internal/webui/server/handler/ — shared request/response/error plumbing.
  • internal/webui/server/realtime/ — the single SSE writer seam.
  • internal/webui/handlermux/, modbuilder/, svcimpl/ — module construction and wiring glue.

The frontend

  • src/api/ — the only place allowed to make HTTP calls. An AST linter bans fetch() everywhere else under src/. Long-lived connections are the exception and are not policed: check-no-raw-fetch.mjs matches only bare/window/globalThis fetch, so EventSource and WebSocket are opened straight from hooks and components (src/hooks/workflows/useWorkflowRunStreams.ts:207, src/components/TerminalView/instances/terminalConnection.ts:180). If you are chasing a stream or a terminal, do not search src/api/.
  • src/views/ — one file per route page, barrel-exported.
  • src/components/ — ~96 component directories. A component may only import another through its directory's index.ts barrel; enforced by a second AST linter with a five-entry allowlist.
  • src/stores/ (zustand), src/hooks/, src/contexts/, src/types/ (including types/generated/openapi.ts).
  • src/router.tsx — declares itself the single source of truth for routes.

Patterns you are expected to copy

Command self-registration
Package-level *cobra.Command vars, flags and subcommands wired in init(), ending in cli.RegisterCommand(root). exemplar: internal/cli/repo/repo_cmd.go:32-81
Noun-verb surface
loom <noun> add|list|show|remove, plus set <NAME> <KEY> <VALUE> / unset for field edits. Creation-time flags live on add, never on set. exemplar: internal/cli/role/role_cmd.go:73-136
Commands do not open stores
Wrap the body in cmdstore.WithActiveWorkspace(func(ctx, h, ws) error {…}). This keeps local/cloud selection inside bootstrap — which is what the control-plane path guard enforces. exemplar: internal/cli/repo/repo_cmd.go:83-116
Compensating rollback
A multi-step command undoes its own partial work. repo add clones, creates the record, and on failure deletes both. exemplar: internal/cli/repo/repo_cmd.go:86-112
HTTP module objects
New<Thing>Module(deps…) plus Register(mux) containing only pattern-to-handler lines. No logic in the module. exemplar: internal/webui/handlers/issues/module.go:27-64
Handler = closure over a service
func Handle<X>(svc service.XService) http.HandlerFunc. Never reach past the service layer.
One contract, two generated clients
api/openapi.yaml generates Go models and TS types. Both directions are staleness-gated, so regenerate rather than hand-editing.
Ratchet, never exempt
Architectural checks carry allowlists of grandfathered ceilings that may shrink but never grow. Splitting the file or package is the expected fix.
Structured logging only
log/slog. log.Printf is banned in new Go files.
No raw exec.Command in unit tests
Use DI interfaces. Integration/e2e/container-tagged files are exempt.

Traps worth knowing before they cost you an afternoon

Verified doc/code conflicts

The default AI backend is codex, not claude. ResolveBackendName() falls back to backendnames.Codex (internal/cli/backend.go:84-94), while README.md:261 states the default is claude. The code is what runs.

loom serve alone serves no web UI

registerFrontendRoutes returns immediately when FrontendDir is empty, and that is the default (internal/webui/app/frontend.go:11-16). Non-/api paths then fall through to Go's plain-text 404 — the frontend is expected to be served externally by a reverse proxy or Vite (internal/webui/app/routes.go:26-30). Use make dev, or pass --frontend-dir internal/webui/frontend/dist.

  • Grep for the path string, not the package. Some routes are registered by a different module than you would guess — …/issues/graph is registered by the workspace-ops module.
  • PATCH routes must go on the outer mux. Registered inside a nested workspace module, a PATCH route hangs rather than 404s.
  • Modules are conditional. A Register you found may never run — most require a non-nil store, terminal service, or SSE hub. A test pins the exact module count per configuration, so adding one means updating that test.
  • git push runs the full gate via the pre-push hook, which make dev installs whether you asked or not. Budget the time.
  • A fresh worktree always reinstalls npm deps, because worktrees do not inherit the parent's ignored files. Your first make gate in a new worktree is slow — that is expected, not broken.
  • ~/.loom/state.json is a cache, not config. Runtime commands do not use it as an implicit default; set LOOM_WORKSPACE or pass --workspace.
  • make test is not the gate's tests. The gate runs go test -p 1 -race over everything with a 60% floor; make test is a lighter script.
  • Local-mode compose stacks are shared machine state. See Lesson 03 — this one can destroy a colleague's data.
