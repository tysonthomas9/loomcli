# cortex-v7 — UI design screenshots

> **Status:** Asset index · *written 2026-07-23*. Images only; no design
> document accompanies them.

Seven PNG mockups added 2026-07-07, named for the surface each one shows:
`sidebar-view`, `sidebar-task-detail`, `kanban-view`, `task-detail-panel`,
`agent-panel-info`, `agent-panel-review`, `talk-to-lead-terminal`.

There is no written spec for this set — nobody recorded which parts were
accepted. Treat them as reference imagery, not as a contract, and prefer a doc
with a status banner when the two disagree.

"cortex" is a **dead UI codename**. It names no package, route, or component;
it survives only as a localStorage key prefix. Do not use it in new prose — see
[`../../loom-glossary.md`](../../loom-glossary.md) and the glossary-safety note
in
[`../../epics/cortex-ui-v6-workspace-redesign.md`](../../epics/cortex-ui-v6-workspace-redesign.md).
These files are v7 assets and postdate that v6 epic; the epic does not
reference them.
