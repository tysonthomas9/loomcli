# Reference docs

> **Status:** Current index · *audited 2026-08-03*

Machine-generated reference material. **Every `.md` here except the
`*.preamble.md` files is generated — never hand-edit one.** Each generated page
carries a `<!-- Code generated by scripts/loomdoc. DO NOT EDIT. -->` header.

| Doc | What it covers | Source of truth |
|---|---|---|
| [env-vars.md](./env-vars.md) | Every `LOOM_*` environment variable the Go source reads, with the packages that read it and a name-based sensitivity flag. | `os.Getenv`/`LookupEnv`/`Setenv` call sites and `LOOM_*` string constants in git-tracked Go, resolved through `go/types`. |
| [cli.md](./cli.md) | The complete `loom` command tree — every command, flag, and inherited persistent flag, hidden commands included. | The assembled cobra tree (`cli.AssembleRootCmd`, `internal/cli/root.go`). |
| [architecture.md](./architecture.md) | The `internal/…` package layers, which imports may cross which boundary, the real cross-layer import graph, and drift between the two. | The depguard rules in `.golangci.yml` plus the compiled import graph. |

Each page splices in a hand-written preamble that carries the rationale and the
method's limits — [env-vars.preamble.md](./env-vars.preamble.md),
[cli.preamble.md](./cli.preamble.md),
[architecture.preamble.md](./architecture.preamble.md). **Those are the files to
edit.** Read a page's preamble before trusting its table: each one states what
its generator deliberately does not count.

## Regenerating

```sh
make docs-gen     # regenerates all three, and docs/api.md as well
```

`make check-go` step [13/15] (`scripts/check-loomdoc-staleness.sh`) fails when a
committed page no longer matches its generated source or its preamble.

## What "git-tracked source" excludes

The filter is **gitignored**, not *untracked* (`scripts/loomdoc/common.go:59-67`).
A brand-new, not-yet-committed file — a fresh `doc.go`, say — is untracked but
not ignored, so it is included, and regenerating on a dirty working tree does
not silently drop packages. What *is* removed is any package containing a
gitignored file: the ~200 session directories under `internal/cli/*/sessions`
and `internal/cli/*/automode/sessions`, plus anything else `.gitignore` names.

So a package missing from `architecture.md` is usually not a generation bug.
`internal/leadcontrol` and 72 other `internal/` packages are absent from the
layer tables because **no depguard rule's file globs match them** — they are
listed by name under *Gaps and drift*.
